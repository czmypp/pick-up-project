## 4. RolePermission.vue - 角色权限分配页（核心）

```
RolePermission.vue
├── 顶部: 角色选择
│   └── el-select (选择角色) → 加载该角色的菜单+接口权限
│
├── 三栏布局:
│   │
│   ├── 左栏: 菜单权限
│   │   └── el-tree (check-strictly 独立选择)
│   │       ├── 节点格式: [图标] 菜单名称 (权限标识)
│   │       ├── 类型图标: DIR=文件夹 / MENU=页面 / BTN=按钮
│   │       ├── 全选/取消全选
│   │       └── 展开/折叠全部
│   │
│   └── 右栏: 接口权限
│       ├── 操作栏: el-button (新增API权限)
│       └── el-table
│           ├── 请求方法标签 (GET=绿 / POST=蓝 / PUT=橙 / DELETE=红)
│           ├── 接口路径 pathPattern
│           ├── 描述
│           └── 操作: [编辑 / 删除]
│       │
│       └── 新增/编辑 API Dialog
│           ├── el-select (请求方法)
│           ├── el-input (路径模式: /api/v1/xxx/**)
│           └── el-input (描述)
│
└── 底部: el-button type="primary" (保存权限) → PUT .../menus + PUT .../apis
```

## 5. MenuList.vue - 菜单管理页

```
MenuList.vue
├── 操作栏: el-button (新建根菜单)
├── el-table (tree 模式)
│   ├── 列:
│   │   ├── 菜单名称
│   │   ├── 图标 icon
│   │   ├── 路由路径 path
│   │   ├── 组件路径 component
│   │   ├── 权限标识 permission
│   │   ├── 类型标签 (DIR=灰 / MENU=蓝 / BTN=橙)
│   │   ├── 可见状态 el-switch
│   │   ├── 排序号
│   │   └── 操作: [新增子级 / 编辑 / 删除 / 上移 / 下移]
│   └── 树展开/折叠
│
└── MenuForm.vue Dialog - 类型联动:
    │
    ├── 当 type == 'DIR' (目录):
    │     └── 显示: 名称 / 图标 / 排序 / 可见 / 上级
    │     └── 隐藏: path / component / permission
    │
    ├── 当 type == 'MENU' (菜单):
    │     └── 显示: 名称 / 图标 / 路径 / 组件 / 排序 / 可见 / 上级
    │     └── 可选: permission (权限标识)
    │
    └── 当 type == 'BTN' (按钮):
          └── 显示: 名称 / 权限标识 / 排序 / 上级
          └── 隐藏: 图标 / 路径 / 组件 / 可见
          └── 仅可关联 type='MENU' 或 type='DIR' 的上级
```

## 6. Pinia 核心 Store

### userStore.ts

```typescript
export const useUserStore = defineStore('user', () => {
  const userList = ref<User[]>([])
  async function fetchUsers(params)      { /* GET /admin/users */ }
  async function createUser(data)        { /* POST /admin/users */ }
  async function updateUser(id, data)    { /* PUT /admin/users/{id} */ }
  async function assignRoles(uid, rids)  { /* PUT /admin/users/{id}/roles */ }
  async function resetPassword(id)       { /* POST /admin/users/{id}/reset-pwd */ }
  async function toggleStatus(id)        { /* PUT /admin/users/{id}/status */ }
  return { userList, fetchUsers, createUser, updateUser, assignRoles, resetPassword, toggleStatus }
})
```

### roleStore.ts

```typescript
export const useRoleStore = defineStore('role', () => {
  async function fetchRoleMenus(roleId)  { /* GET /admin/roles/{roleId}/menus */ }
  async function fetchRoleApis(roleId)   { /* GET /admin/roles/{roleId}/apis */ }
  async function assignMenus(rid, mIds)  { /* PUT /admin/roles/{id}/menus */ }
  async function assignApis(rid, apis)   { /* PUT /admin/roles/{id}/apis */ }
  return { fetchRoleMenus, fetchRoleApis, assignMenus, assignApis }
})
```

### menuStore.ts

```typescript
export const useMenuStore = defineStore('menu', () => {
  const menuTree = ref<MenuNode[]>([])
  async function fetchMenuTree()         { /* GET /admin/menus */ }
  async function createMenu(data)        { /* POST /admin/menus */ }
  async function updateMenu(id, data)    { /* PUT /admin/menus/{id} */ }
  async function deleteMenu(id)          { /* DELETE /admin/menus/{id} */ }
  async function updateSortOrder(id, o)  { /* PUT /admin/menus/{id}/sort */ }
  return { menuTree, fetchMenuTree, createMenu, updateMenu, deleteMenu, updateSortOrder }
})
```

## 7. 路由配置

| 路由 | 组件 | 权限 |
|------|------|------|
| `/system/users` | UserList.vue | `user:view` |
| `/system/roles` | RoleList.vue | `role:view` |
| `/system/roles/:id/permission` | RolePermission.vue | `role:assign` |
| `/system/menus` | MenuList.vue | `menu:view` |
| `/system/config` | ConfigForm.vue | 已认证 |
