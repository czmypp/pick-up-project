# M4 模板管理 - 前端执行方案

> **依赖**：M1（认证鉴权）、M5（系统管理-菜单）
> **涉及表**：`t_project_template`、`t_function_module`、`t_layout_rule`、`t_template_function`、`t_template_layout`、`t_feature`、`t_feature_template`

---

## 1. 目录结构

```
system/
├── pages/
│   ├── templates/
│   │   ├── TemplateList.vue          // 模板列表页
│   │   └── TemplateForm.vue          // 模板编辑/新建页
│   ├── modules/
│   │   ├── ModuleList.vue            // 功能模块库页
│   │   └── ModuleForm.vue            // 功能模块表单 Dialog
│   ├── layouts/
│   │   ├── LayoutList.vue            // 排版规则库页
│   │   └── LayoutForm.vue            // 排版规则表单
│   └── features/
│       ├── FeatureList.vue           // 功能管理页
│       └── FeatureForm.vue           // 功能节点表单
├── stores/
│   ├── templateStore.ts
│   ├── moduleStore.ts
│   ├── layoutStore.ts
│   └── featureStore.ts
└── router/
    └── system.routes.ts (模板管理部分)
```

## 2. TemplateList.vue - 模板列表页

```
TemplateList.vue
├── 筛选栏
│   ├── el-select (分类: 电商/CMS/小程序/管理后台/API)
│   ├── el-input (关键字搜索)
│   └── el-button (新建模板)
├── el-card 网格
│   ├── 每个模板一张卡片
│   │   ├── 模板名称
│   │   ├── 分类标签 el-tag
│   │   ├── 项目类型标签
│   │   ├── 使用次数统计
│   │   ├── 状态开关 el-switch
│   │   └── 操作: [编辑 / 复制 / 删除]
│   └── 空状态占位
└── el-pagination
```

## 3. TemplateForm.vue - 模板编辑/新建页

```
TemplateForm.vue
├── 基本信息表单
│   ├── el-input (模板名称 *)
│   ├── el-input (模板编码 *) + 唯一性校验
│   ├── el-select (分类 *)
│   ├── el-select (项目类型 *)
│   ├── el-input textarea (描述)
│   └── el-input textarea (默认需求描述)
│
├── 技术栈配置 Tab
│   ├── el-input (前端技术栈)
│   ├── el-input (后端技术栈)
│   ├── el-input (数据库)
│   └── el-input (缓存)
│
├── 关联功能模块 Tab
│   ├── el-transfer 穿梭框（左右选择）
│   │   ├── 左侧: 所有可用模块列表
│   │   │   └── [模块名称] - [领域标签] - [描述]
│   │   └── 右侧: 已选模块列表
│   │       └── el-checkbox (标记必选/可选) + 拖拽排序
│   └── 已选模块排序: 拖拽调整顺序
│
├── 关联排版方案 Tab
│   ├── el-checkbox-group
│   │   └── [排版名称] - [排版类型] - [适用场景]
│   └── el-radio (标记默认排版)
│
└── 底部: 保存 / 取消 按钮
```

## 4. ModuleList.vue - 功能模块库页

```
ModuleList.vue
├── 筛选栏
│   ├── el-select (领域: 全部/GENERAL/ECOMMERCE/CMS/MINI_PROGRAM/ADMIN)
│   ├── el-radio-group (核心/非核心/全部)
│   └── el-input (关键字搜索)
├── 操作栏
│   ├── el-button (新建模块)
│   ├── el-button (批量启用)
│   ├── el-button (批量禁用)
│   ├── el-button (批量导出 Excel)
│   └── el-upload (批量导入)
├── el-table
│   ├── 模块名称
│   ├── 模块标识 module_key
│   ├── 领域标签 el-tag
│   ├── 标签列表 el-tag 组
│   ├── 核心模块标记
│   ├── 排序号
│   ├── 启用状态 el-switch
│   └── 操作: [编辑 / 删除]
└── el-pagination
```

## 5. LayoutList.vue - 排版规则库页

```
LayoutList.vue
├── 操作栏: el-button (新建排版规则)
├── el-table
│   ├── 排版名称
│   ├── 排版类型标签
│   ├── 适用场景标签组
│   ├── 启用状态 el-switch
│   └── 操作: [编辑 / 预览 / 删除]
└── el-pagination
```

## 6. LayoutForm.vue - 排版规则表单

```
LayoutForm.vue (Dialog)
├── el-input (排版名称 *)
├── el-select (排版类型: SidebarLayout/HeaderMainFooter/...)
├── el-input textarea (描述)
├── JSON 配置编辑器 (codemirror / monaco)
│   └── 代码高亮 + 自动补全 + 格式校验
├── 实时预览: 右栏显示当前配置的效果示意
├── el-select (适用场景多选)
└── 底部: 确认 / 取消
```

## 7. FeatureList.vue - 功能管理页

```
FeatureList.vue
├── el-tree
│   ├── 树节点: [图标] 功能名称 (功能标识)
│   ├── 节点操作:
│   │   ├── 新增子节点 (el-dropdown-item)
│   │   ├── 编辑
│   │   ├── 禁用/启用
│   │   └── 删除
│   └── 展开/折叠全部
├── 批量操作栏
│   ├── el-button (批量启用)
│   ├── el-button (批量禁用)
│   └── el-button (批量移动到指定父级)
├── 新建根节点按钮
└── 关联模板 Dialog: 可查看/编辑功能关联的模板
```

## 8. FeatureForm.vue - 功能节点表单

```
FeatureForm.vue (Dialog)
├── el-tree-select (上级功能)
├── el-input (功能名称 *)
├── el-input (功能标识 feature_key *)
├── el-input textarea (描述)
├── el-input (图标图标名)
└── el-switch (启用状态)
```

## 9. 路由配置

| 路由 | 组件 | 权限 |
|------|------|------|
| `/system/templates` | TemplateList.vue | `template:view` |
| `/system/templates/:id` | TemplateForm.vue | `template:view/write` |
| `/system/modules` | ModuleList.vue | `module:view` |
| `/system/layouts` | LayoutList.vue | `layout:view` |
| `/system/features` | FeatureList.vue | `feature:view` |
